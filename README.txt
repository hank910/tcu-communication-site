慈濟大學傳播學系網站重設計（課程作品）

檔案結構：
- index.html：系所首頁
- studentworks.html：學生作品展示頁
- graph/：網站圖片素材（SVG）

部署方式：
1. 將此資料夾內所有檔案上傳到 GitHub Repository 根目錄。
2. Repository 設為 Public。
3. Settings → Pages → Build and deployment 選 Deploy from a branch。
4. Branch 選 main，資料夾選 /(root)，按 Save。
5. 等待 GitHub Pages 部署完成，網址通常為 https://你的帳號.github.io/專案名稱/。
   若 Repository 名稱是「你的帳號.github.io」，網址通常為 https://你的帳號.github.io/。

注意：
- HTML 的 CSS 與 JavaScript 均為內嵌。
- 圖片皆使用 graph/ 相對路徑。
- 學生作品頁中的作品名稱與插圖是展示版型示意，正式繳交前請替換為自行拍攝／製作且已取得授權的素材。
- 這份資料夾尚未上傳至你的 GitHub 帳號，因此尚未產生公開網址。
